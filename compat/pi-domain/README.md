# pi-domain is now pi-retainer

This package only keeps existing installs working. It bundles [pi-retainer](https://www.npmjs.com/package/pi-retainer) and loads it.

Switch when you can:

```bash
pi remove npm:pi-domain
pi install npm:pi-retainer
```

Your memories, settings and snapshots carry over. See [Moving from pi-domain](https://github.com/one24-ai/pi-retainer#moving-from-pi-domain).
